# Cursor first session (painless)

You have not used Cursor much. Use only this.

1. Open this folder as the project (not a parent folder).
2. Wait until indexing settles. You can ignore most popups except “allow file edits” / terminal.
3. Open the **Agent** panel (Composer). One chat.
4. Attach nothing extra. The rules files are already in the repo.
5. Paste `prompts/B0-B1.md` in full. Send.
6. Approve `npm install` and `node scripts/check-core.mjs` when asked.
7. When it says it is done, run `npm run check` yourself in the terminal.
8. Run `npm run dev`, open the local URL, see gears.
9. Close the chat. Do not ask “now make it a luxury watch.”

If Composer wants to use Plan mode for this burst: decline, or let it plan only B0+B1. A multi-week plan is noise.

If you get lost: `Stop. Only B1. Do not edit vendor.`
